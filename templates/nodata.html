Data Required

No match data found. Download real data from Oracle's Elixir to use the predictor.

Option 1: Automatic download

python main.py download

Downloads from Oracle's Elixir S3 / Google Drive (needs internet access).

Option 2: Manual download

  1. Go to oracleselixir.com/tools/downloads
  2. Download CSV files for the years you need (2024, 2025, 2026)
  3. Save them to the data/ folder as:
    data/2024_matches.csv
    data/2025_matches.csv
    data/2026_matches.csv
  4. Or use the import command:
    python main.py import ~/Downloads/2026_LoL_esports_match_data_from_OraclesElixir_20260218.csv
  5. Restart python web.py

Option 3: Sample data (for testing only)

python main.py generate

Generates simulated data. Not real match results.
